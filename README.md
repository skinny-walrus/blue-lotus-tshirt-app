# Blue Lotus T-Shirt Creator

Interactive, iPad-friendly interface mockup for the Blue Lotus Temple charity T-shirt workflow.

## Current mockup

- Choose a dog breed, message, and shirt color
- Preview the back design
- Approve the design for print preparation
- Shows the production target: 9 × 11.5 inches, 300 DPI, transparent PNG

Open `index.html` in a browser or serve this folder with any static HTTP server.

The final production workflow will preserve the exact approved artwork and prepare it without regenerating the image.
